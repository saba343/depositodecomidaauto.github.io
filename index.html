Introdução ao Projeto

Desenvolvimento de um sistema automatizado e inteligente para a gestão e distribuição controlada de alimentação animal.

Visão Geral do Projeto

O DepósitoComidaAuto surge como uma resposta tecnológica para otimizar a rotina de alimentação animal, minimizando o desperdício e garantindo que as porções corretas sejam entregues nos momentos ideais. O projeto foca na criação de um dispositivo físico robusto integrado com uma camada de controlo inteligente, permitindo a monitorização contínua do stock de ração restante e o agendamento preciso das refeições.

Objetivos Principais

Automação Eficiente

Substituir a necessidade de intervenção humana direta na distribuição diária de ração através de um mecanismo eletromecânico confiável.

Agendamento Preciso

Permitir a configuração de rotinas alimentares rígidas baseadas em horários específicos e quantidades pré-determinadas para manter a saúde do animal.

Controlo de Stock

Monitorizar o nível do depósito em tempo real, emitindo alertas visuais ou digitais assim que a quantidade de comida atingir um limite crítico.

Tecnologias Planeadas

Hardware / Componentes

Microcontrolador (Arduino / ESP32) Servomotor / Motor de Passo Sensor Ultrassónico (Nível) Módulo RTC (Relógio de Tempo Real) Display LCD / LEDs Indicadores

Software / Integração

C++ (Firmware) HTML5 / CSS3 (Interface) Protocolo MQTT / HTTP

Cronograma de Desenvolvimento

Fase 1: Investigação e Requisitos

Levantamento de necessidades, escolha de componentes eletrónicos e desenho do modelo estrutural do depósito.

Fase 2: Prototipagem de Hardware

Montagem dos circuitos em breadboard, calibração dos sensores de nível e testes iniciais com o motor atuador.

Fase 3: Desenvolvimento de Software

Programação da lógica de agendamento no microcontrolador e criação da interface web básica para acompanhamento.

Fase 4: Integração e Testes Finais

Junção do ecossistema físico e digital, testes de stress do mecanismo sob carga e ajustes finais de precisão.
